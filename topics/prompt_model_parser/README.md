# LangChain Core Concepts — Prompt, Messages, Parser, Chain, and Invoke

This note explains the core LangChain concepts you need before moving to RAG, memory, tools, and agents.

---

# 1. `ChatPromptTemplate`

Import:

```python
from langchain_core.prompts import ChatPromptTemplate
```

`ChatPromptTemplate` is used to create a reusable **chat-style prompt**.

Example:

```python
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful AI assistant."),
    ("human", "Explain {topic} simply.")
])
```

Here:

```text
{topic}
```

is a variable.

Later:

```python
prompt.invoke({
    "topic": "machine learning"
})
```

LangChain fills the variable.

Conceptually:

```text
Input
  ↓
ChatPromptTemplate
  ↓
System Message
Human Message
```

---

# 2. Why use `ChatPromptTemplate`?

Instead of writing a fixed prompt:

```python
"Explain machine learning"
```

you can create a reusable prompt:

```python
"Explain {topic}"
```

Then use:

```python
{"topic": "machine learning"}
```

or:

```python
{"topic": "deep learning"}
```

or:

```python
{"topic": "Random Forest"}
```

So:

```text
Prompt Template = reusable prompt with variables
```

---

# 3. System Message

Example:

```python
("system", "You are a helpful AI assistant.")
```

The **system message** tells the model:

```text
Who are you?
How should you behave?
What rules should you follow?
```

Examples:

```text
You are a Python teacher.
```

```text
You are a data science tutor.
```

```text
Answer only using the provided context.
```

```text
Give short and simple explanations.
```

Think:

```text
System Message = model instructions / behavior
```

---

# 4. Human Message

Example:

```python
("human", "Explain {topic} simply.")
```

The **human message** represents the user's request.

Example:

```text
Human:
Explain machine learning simply.
```

Think:

```text
Human Message = user input
```

---

# 5. AI Message

When the model responds, LangChain normally returns an `AIMessage`.

Example:

```python
response = model.invoke("What is machine learning?")
```

Conceptually:

```python
AIMessage(
    content="Machine learning is..."
)
```

You can access the text using:

```python
print(response.content)
```

Think:

```text
AI Message = response generated by the model
```

---

# 6. Message Flow

A normal conversation looks like:

```text
SystemMessage
      ↓
HumanMessage
      ↓
AIMessage
      ↓
HumanMessage
      ↓
AIMessage
```

Example:

```text
System:
You are a machine learning tutor.

Human:
What is overfitting?

AI:
Overfitting happens when...

Human:
How can I reduce it?

AI:
You can reduce it using...
```

This becomes especially important when we add **memory**.

---

# 7. Message Classes

You can also create messages directly.

```python
from langchain_core.messages import (
    SystemMessage,
    HumanMessage,
    AIMessage
)
```

Example:

```python
messages = [
    SystemMessage(
        content="You are a helpful AI assistant."
    ),

    HumanMessage(
        content="What is machine learning?"
    )
]

response = model.invoke(messages)

print(response.content)
```

So you do **not always need `ChatPromptTemplate`**.

---

# 8. `StrOutputParser`

Import:

```python
from langchain_core.output_parsers import StrOutputParser
```

Create:

```python
parser = StrOutputParser()
```

Normally the model returns:

```text
AIMessage
```

Example:

```python
AIMessage(
    content="Machine learning is..."
)
```

`StrOutputParser` converts it into:

```text
Normal Python string
```

Example:

```python
"Machine learning is..."
```

Flow:

```text
Model
  ↓
AIMessage
  ↓
StrOutputParser
  ↓
String
```

---

# 9. Why use a parser?

A model does not always return the exact Python data type your application needs.

You may want:

```text
string
JSON
list
dictionary
Pydantic object
```

The parser helps convert the model output into a useful format.

Example:

```text
AIMessage
   ↓
Parser
   ↓
Application-friendly output
```

---

# 10. Do I always need `StrOutputParser`?

No.

You can do:

```python
response = model.invoke("What is machine learning?")

print(response.content)
```

Here:

```text
response = AIMessage
```

and:

```python
response.content
```

gives the text.

So:

```python
StrOutputParser()
```

is mainly useful when building a chain such as:

```python
prompt | model | parser
```

because the final output becomes a normal string automatically.

---

# 11. Other parsers

`StrOutputParser` is only one parser.

## A. `JsonOutputParser`

Useful when you want JSON-like output.

```python
from langchain_core.output_parsers import JsonOutputParser
```

Example desired output:

```json
{
  "topic": "machine learning",
  "difficulty": "beginner"
}
```

---

## B. `PydanticOutputParser`

Useful when you want validated structured Python data.

```python
from langchain_core.output_parsers import PydanticOutputParser
```

However, with modern chat models, another very useful option is:

```python
model.with_structured_output(...)
```

Example:

```python
from pydantic import BaseModel


class Answer(BaseModel):
    topic: str
    difficulty: str


structured_model = model.with_structured_output(Answer)
```

Then the result can be:

```python
Answer(
    topic="machine learning",
    difficulty="beginner"
)
```

---

## C. No parser

You can simply use:

```python
response = model.invoke(...)
print(response.content)
```

This is perfectly fine for simple programs.

# 12. What is a Chain?

A **chain** connects multiple LangChain components together.

Example:

```python
chain = prompt | model | parser
```

Think:

```text
Step 1
  ↓
Step 2
  ↓
Step 3
```

For example:

```text
Prompt
  ↓
Model
  ↓
Parser
```

The output of one component becomes the input of the next component.

---

# 13. Chain Order

For this code:

```python
chain = prompt | model | parser
```

the correct order is:

```text
Input Dictionary
      ↓
Prompt Template
      ↓
Chat Messages
      ↓
Model
      ↓
AIMessage
      ↓
Parser
      ↓
Final Output
```

Example:

```python
chain.invoke({
    "input": "Explain machine learning"
})
```

Step by step:

```text
{"input": "Explain machine learning"}
                ↓
             prompt
                ↓
System + Human messages
                ↓
              model
                ↓
           AIMessage
                ↓
             parser
                ↓
              string
```

---

# 14. Why was this wrong?

Wrong:

```python
chain = model | prompt | parser
```

Why?

Because the input:

```python
{
    "input": "Explain machine learning"
}
```

goes directly to the model.

But a chat model normally expects:

```text
string
PromptValue
list of messages
```

not a prompt-variable dictionary.

So:

```text
Dictionary
   ↓
Model
```

is wrong in this case.

Correct:

```text
Dictionary
   ↓
Prompt
   ↓
Model
```

---

# 15. LCEL

This syntax:

```python
prompt | model | parser
```

is part of:

```text
LCEL
```

which stands for:

```text
LangChain Expression Language
```

The `|` operator means:

```text
pass the output of the left side
into the input of the right side
```

Example:

```python
A | B | C
```

means:

```text
A
↓
B
↓
C
```

---

# 16. What is `invoke()`?

Example:

```python
result = chain.invoke({
    "input": "Explain machine learning"
})
```

`invoke()` means:

```text
Run this LangChain component once with one input.
```

Think:

```text
invoke = execute one input
```

Example:

```python
model.invoke(...)
```

runs the model once.

```python
prompt.invoke(...)
```

formats the prompt once.

```python
chain.invoke(...)
```

runs the whole chain once.

---

# 17. `prompt.invoke()`

You can run only the prompt:

```python
formatted_prompt = prompt.invoke({
    "input": "What is machine learning?"
})

print(formatted_prompt)
```

This helps you understand what messages the prompt creates.

---

# 18. `model.invoke()`

You can run only the model:

```python
response = model.invoke(
    "What is machine learning?"
)

print(response.content)
```

---

# 19. `chain.invoke()`

This runs everything:

```python
result = chain.invoke({
    "input": "What is machine learning?"
})
```

Flow:

```text
Prompt
 ↓
Model
 ↓
Parser
```

---

# 20. Alternatives to `invoke()`

`invoke()` is not the only way to run a LangChain component.

---

## A. `batch()`

Use when you have multiple inputs.

```python
results = chain.batch([
    {"input": "Explain machine learning"},
    {"input": "Explain deep learning"},
    {"input": "Explain Random Forest"},
])
```

Think:

```text
Input 1 → Output 1
Input 2 → Output 2
Input 3 → Output 3
```

Use:

```text
batch()
```

when processing multiple inputs.

---

## B. `stream()`

Use when you want output gradually.

```python
for chunk in chain.stream({
    "input": "Write a short story"
}):
    print(chunk, end="")
```

Think:

```text
invoke()
→ wait for complete answer

stream()
→ receive answer piece by piece
```

Streaming is useful for chat applications.

---

## C. `ainvoke()`

Asynchronous version of `invoke()`.

```python
result = await chain.ainvoke({
    "input": "Explain machine learning"
})
```

Useful in:

```text
FastAPI
async applications
high-concurrency systems
```

---

## D. `abatch()`

Async version of `batch()`.

```python
results = await chain.abatch([...])
```

---

## E. `astream()`

Async version of streaming.

```python
async for chunk in chain.astream({
    "input": "Explain AI"
}):
    print(chunk)
```

---

# 21. Alternatives to `ChatPromptTemplate`

You do not always need `ChatPromptTemplate`.

---

## A. Direct string

Simplest option:

```python
response = model.invoke(
    "Explain machine learning simply."
)

print(response.content)
```

Flow:

```text
String
 ↓
Model
```

Use this for very simple programs.

---

## B. Direct messages

```python
from langchain_core.messages import (
    SystemMessage,
    HumanMessage
)


messages = [
    SystemMessage(
        content="You are a teacher."
    ),

    HumanMessage(
        content="Explain machine learning."
    )
]


response = model.invoke(messages)
```

Use this when you want chat messages but do not need reusable variables.

---

## C. `PromptTemplate`

For simple text-style prompts:

```python
from langchain_core.prompts import PromptTemplate


prompt = PromptTemplate.from_template(
    "Explain {topic} simply."
)
```

Think:

```text
PromptTemplate
→ text prompt

ChatPromptTemplate
→ chat messages
```

For chat models, `ChatPromptTemplate` is usually more natural.

---

## D. Few-shot prompts

If you want to provide examples:

```text
Input: happy
Output: positive

Input: terrible
Output: negative

Input: amazing
Output: ?
```

LangChain also supports few-shot prompt templates.

Use them when examples help teach the model the desired behavior.
